# Blender assets

These original models are generated by `art/build_assets.py` using Blender 4.5.

- `coupe-body.glb`: beveled coupe body, boolean-cut wheel arches, window frames, lights, grille and trim.
- `coupe-wheel.glb`: axle-centered tire, tread blocks, split spokes, brake disc and sidewall rotation marker.
- `sandstone.glb`: displaced sandstone mesh reused around the track.

The editable source is `art/dust-coupe.blend`. Exported GLB axes are X right, Y up, Z forward. Wheel radius is 0.45 m, wheelbase is 2.6 m. Each wheel is wrapped in separate steering and rolling groups by the game.

Geometry is merged by material before export to reduce draw calls. All models are authored for this repository; no downloaded third-party vehicle model is used. Three.js dependencies retain their upstream MIT license under `vendor/LICENSE`.
